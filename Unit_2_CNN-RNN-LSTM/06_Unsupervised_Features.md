# Unsupervised Features

## Overview

Unsupervised learning extracts features without labels.

Goal:

Learn useful representations automatically.

---

## Why Needed?

Labeling data is expensive.

Unsupervised learning uses abundant unlabeled data.

---

## Feature Learning

Model learns:

- Edges
- Shapes
- Patterns
- Structures

without supervision.

---

## Autoencoders

Learn compressed representations.

Input → Encoder → Decoder → Output

---

## Self-Supervised Learning

Creates artificial labels from data itself.

Examples:

- BERT
- SimCLR
- CLIP

---

## Contrastive Learning

Learns by comparing similar and dissimilar samples.

Example:

Two augmented images of same cat should be close.

---

## Applications

- Image Retrieval
- Representation Learning
- Recommendation Systems

---

## Summary

Unsupervised feature learning discovers useful patterns without labeled data.
