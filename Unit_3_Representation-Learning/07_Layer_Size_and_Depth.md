# Layer Size and Depth

## Overview

Neural network performance depends on:

- Width (layer size)
- Depth (number of layers)

---

## Width

Number of neurons in a layer.

Example:

Input → 128 → Output

Width = 128

---

## Depth

Number of hidden layers.

Example:

Input → H1 → H2 → H3 → Output

Depth = 3

---

## Shallow Networks

Characteristics:

- Fewer layers
- Simpler models

Advantages:

- Easy training

Disadvantages:

- Limited expressiveness

---

## Deep Networks

Characteristics:

- Many layers

Advantages:

- Hierarchical learning
- Powerful representations

Disadvantages:

- Harder training

---

## Tradeoff

Increasing depth and width:

Pros:
- Better learning

Cons:
- More computation
- Risk of overfitting

---

## Summary

Network performance depends heavily on choosing appropriate width and depth.
